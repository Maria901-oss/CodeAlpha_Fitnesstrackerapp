# CodeAlpha_FitnessTracker
Task 3 - Fitness Tracker App (Kotlin, SQLite, Material 3).
Features: log workouts/steps/calories, daily progress bars, 7-day bar chart + summary,
editable daily goals, delete entries, local SQLite storage, responsive on all screen sizes.

Run: open this folder in Android Studio (Hedgehog or newer) -> wait for Gradle sync -> Run.
APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
